# Experiment 5 — JavaScript Fundamentals

**SAP ID:** 590014609

**Course:** Backend Development

---

## 🎯 Aim & Objectives

### Aim
To understand JavaScript fundamentals used in backend development, including arrays, objects, functions, strings, and basic data manipulation.

### Key Objectives
1. Create and modify arrays and objects.
2. Define and call reusable JavaScript functions.
3. Apply string methods and array methods.
4. Implement basic create, read, and update operations.
5. Build a simple in-memory library data structure.

---

## 📚 Theoretical Background

JavaScript arrays store ordered collections, while objects store related key-value data. Functions package reusable logic, and methods such as `push()`, `find()`, `map()`, and `filter()` make it possible to process application data. These concepts form the foundation of Node.js and Express applications.

This experiment demonstrates core JavaScript concepts used in backend development: arrays, objects, functions, strings, collection operations, and a simple library data structure.

## Files

- `script.js` — demonstrates arrays, objects, and functions.
- `script2.js` — demonstrates string methods and add/read/update operations for arrays and objects.
- `library.js` — implements a small in-memory library with functions to add and find books.

## Run the examples

The files are standalone JavaScript programs. Run them with Node.js from this directory:

```bash
node script.js
node script2.js
node library.js
```

This experiment does not start a web server and does not use `localhost:5000`. The results appear in the terminal.

The output is printed in the terminal and includes the results of each operation.

## Concepts covered

- Array creation and `push()`.
- Object properties and property updates.
- Function declarations and template strings.
- String methods such as `toUpperCase()`, `toLowerCase()`, and `split()`.
- Searching arrays with `find()`.
- Basic create, read, and update operations on JavaScript data structures.
