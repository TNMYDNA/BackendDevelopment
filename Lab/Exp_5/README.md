# Experiment 5 — JavaScript Fundamentals

**SAP ID:** 590014609

This experiment demonstrates core JavaScript concepts used in backend development: arrays, objects, functions, strings, collection operations, and a simple library data structure.

## Files

- `script.js` — demonstrates arrays, objects, and functions.
- `script2.js` — demonstrates string methods and add/read/update operations for arrays and objects.
- `library.js` — implements a small in-memory library with functions to add and find books.

## Run the examples

The files are standalone JavaScript programs. Run them with Node.js from this directory:

```bash
node script.js
node script2.js
node library.js
```

The output is printed in the terminal and includes the results of each operation.

## Concepts covered

- Array creation and `push()`.
- Object properties and property updates.
- Function declarations and template strings.
- String methods such as `toUpperCase()`, `toLowerCase()`, and `split()`.
- Searching arrays with `find()`.
- Basic create, read, and update operations on JavaScript data structures.
